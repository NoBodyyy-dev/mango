# Манго — сайт студии

Статический многостраничный сайт без сборки. Зелёная тема бренда (`#0B2E22`), один акцент манго `#FF8A2A`.

```
site/
  index.html      главная
  prices.html     общие цены «от»
  projects.html   проекты: ПлатОН
  legal.html      реквизиты, условия, оферта, персональные данные
  styles.css      вся вёрстка и CSS-анимации
  assets/mango.svg  векторный знак и favicon по референсу
  app.js          контакты, окно «Записаться», меню, анимации прокрутки
  _build.py       генератор четырёх страниц (общие шапка, подвал и окно)
  _old-2026-09-21/  прошлая версия сайта
```

Страницы собираются скриптом: общие части описаны один раз в `_build.py`.
Правьте тексты там и запускайте `python3 _build.py` (путь `OUT` в начале файла).
Если правите HTML руками, меняйте шапку и подвал во всех четырёх файлах.
После правки `styles.css` или `app.js` увеличьте `?v=` в `_build.py`, чтобы браузеры не держали старую версию.

## Локальный запуск

```bash
cd site && python3 -m http.server 8080
```

## Библиотеки (с CDN)

- GSAP 3.12 + ScrollTrigger (cdnjs): появление блоков, закреплённые секции, горизонтальная лента, счётчики
- Lenis (jsDelivr): плавная прокрутка
- Phosphor Icons (jsDelivr): иконки
- Шрифты Unbounded (название студии), Montserrat, Onest, JetBrains Mono (Google Fonts)

Если библиотеки не загрузились или у посетителя включено «уменьшить движение», сайт статичный,
но весь контент виден: начальные состояния анимаций задаёт только JS.

## Анимации по блокам

| Блок | Приём |
|---|---|
| Титульный экран | заголовок поднимается по словам, плод «вырастает» с пружиной, покачивается и следует за курсором, вокруг вращается текст, фон переливается |
| Бегущая строка | ускоряется и меняет направление вместе с прокруткой |
| Услуги | плитки разного размера, подсветка под курсором |
| Манифест | текст проявляется по словам в такт прокрутке |
| Факты | счётчики досчитывают до значения |
| Кейс на главной | левая колонка закреплена, пункты справа появляются по очереди |
| Этапы | карточки наезжают друг на друга стопкой |
| Проекты | горизонтальная лента, которая листается прокруткой вниз |
| Цены | оглавление подсвечивает текущий раздел, строки выезжают по очереди |
| Везде | переходы между страницами (View Transitions), шапка прячется при прокрутке вниз, полоса прогресса, кнопки тянутся к курсору, окно «Записаться» раскрывается от кнопки |

## Кнопка «Записаться»

Открывает окно с выбором Telegram или WhatsApp. Контакты меняются в одном месте:
объект `CONTACTS` в начале `app.js`.

## Что заполнить перед публикацией

- **Номер WhatsApp** в `app.js` — сейчас заглушка `79000000000`
- ИНН, ОГРНИП, счёт, банк и адрес в `legal.html` (помечены «заполнить»)
- Реальные скриншоты ПлатОН (в `projects.html` оставлен комментарий TODO)
- Проверить у юриста раздел «Персональные данные»
- Согласовать публикацию кейса ПлатОН, если по нему есть NDA
- `favicon`, `og:image`, `robots.txt`, `sitemap.xml`, Метрика

## GitHub Pages

Сайт подготовлен к публикации из ветки `main`, папки `/ (root)`.
В настройках репозитория: Settings → Pages → Deploy from a branch → main → / (root) → Save.
Адрес после публикации: https://nobodyyy-dev.github.io/mango/
Файл `.nojekyll` отключает обработку Jekyll для статического сайта.
